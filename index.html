CSS Combinator Selector Name Description
[Element1] > [Element2] Child Combinator Selects the elements that are direct children of Element 1
[Element1] + [Element2] Next Sibling Combinator Selects element 2 that come right after elemement 1
[Element1]" "[Element2] Descendant Selector A space between two selectors. Selects all descendants of element 1 that match element 2
[Element1] ~ [Element2] Subsequent-sibling combinator Selects all siblings of element 1 that match element 2
